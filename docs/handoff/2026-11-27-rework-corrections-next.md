## Rules that must not be broken

- No comments in code files; the reasons live in `DECISIONS.md`.
- Never invent a money amount. Machine-read values are proposals; the user's value wins; non-payment images never pre-fill an amount.
- `app/receipts/templates/receipts.html` and `app/static/receipts.css` are generated by `tools/make_receipt_assets.py`. Edit the generator, re-run it, then verify with `documents/_extract/recon/gen_identity.py`.
- Prove UI work with `.verify/journeys/*` at 390x844 **and** 1280x800, light and dark, and look at the screenshots. Assertions alone are not a design review.
- Use `.venv/Scripts/python.exe`. Never restart 8010 without the owner saying so; run a private instance on 8012 for experiments.
- Shell is `cmd.exe` for background jobs (backslash paths) and bash for foreground (forward slashes). Inline `python -c` is refused; write a script file.
